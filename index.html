tauten

Strict Rust for code written by agents. The mistakes the compiler accepts (unwrap on input, unchecked arithmetic, stubs left behind, dropped errors, library code reading the clock) become checked rules, each with a stable ID and a repair hint.

Pre-release Version 0.0.2 is on crates.io. Development pilot completed; held-out benefit not established (benchmark).

Use it

$cargo install --locked cargo-tauten

Needs Rust 1.98 or newer, with clippy.

# propose a tier for each crate
$ cargo tauten init --write
$ cargo tauten check
# one diagnostic per line, for agents
$ cargo tauten check --format json
$ cargo tauten checkCaptured
error[TAU-P001]: used `unwrap()` on a `Result` value  --> rej-unwrap/src/lib.rs:6:5 (core crate `rej-unwrap`)  = rule: No unwrap/expect on fallible values (enforced by Clippy)  = fix: Propagate with `?` and a typed error, or handle the None/Err case explicitly with match, if let, or a default chosen on purpose.

Captured from the rej-unwrap fixture in the tauten repository at bbb20eb.

What it is

Each crate declares a tier; the less it may touch, the stricter its rules. Dependencies point inward only.

  • kernel Pure, no_std, deterministic decisions; eligible for proofs
  • core Library code; effects arrive as parameters
  • edge Startup and IO; the only tier that may create authority
