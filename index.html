tauten

A discipline for Rust: authority passed explicitly, effects visible in signatures, checked evidence, refinement types, and proofs over the shipped code (Aeneas → Lean), with bounded model checking (TLC) for protocols.

Written for code that agents write and maintain. Agents are the audience, not the claim.

Pre-release Version 0.0.3 is on crates.io; the discipline APIs are in progress. No defect-reduction claim (why).

Use it

$cargo install --locked cargo-tauten

Needs Rust 1.98 or newer, with clippy.

$ cargo tauten check                  # every edit
$ cargo tauten ship                   # end of feature (planned 0.1)
$ cargo tauten verify --level full    # nightly (planned 0.1)
$ cargo tauten verify --level release # on a tag (planned 0.1)
$ cargo tauten checkCaptured
error[TAU-A001]: use of a disallowed method `std::time::SystemTime::now`  --> rej-ambient-clock/src/lib.rs:6:5 (core crate `rej-ambient-clock`)  = rule: No ambient authority (enforced by Clippy)  = fix: Take a capability parameter (for example a `&cap_std::fs::Dir` from `Authority::dir`, `&dyn tauten::cap::Clock`, or `&tauten::cap::Env`) and let an edge crate construct it.

Captured from the rej-ambient-clock fixture in the tauten repository at 8fb6ade: a core crate read the clock instead of taking it as a parameter.

Four ideas

  • Authority passed explicitly ●Exercised In progress Core code takes the clock, the environment or a directory as a parameter; only the edge creates them.
  • Effects visible in signatures In progress Planned Capability parameters, Result and async are a function's effect row; #[effects(..)] states it and a check compares the two.
  • Checked evidence In progress A check returns evidence that borrows what it checked, so changing the state before acting on it does not compile.
  • Refinement types ●Exercised Planned A value with a rule is a type that can only be built through its check; in kernel crates that check is proved.

Proofs over the shipped code, on a cadence. ●Exercised Planned (0.1) Planned Kernel crates are translated to Lean with Charon and Aeneas; theorems about that translation are axiom-audited and calibrated with mutants.
