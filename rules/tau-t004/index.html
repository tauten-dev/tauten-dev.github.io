Rules / TAU-T004

Declared layers point backwards

decided by Tauten kernel deny core deny edge deny
Applies to tests: yes Exceptions: never

Why

Inside a tier, a workspace may order its crates in named layers ([workspace.metadata.tauten] layers); a crate that uses a later layer turns the intended dependency order into a cycle waiting to happen.

Fix

Move the shared code into the same or an earlier layer, or declare the crate in a later layer. Give every crate a layer from the workspace's list.

In the terminal

$cargo tauten explain TAU-T004
