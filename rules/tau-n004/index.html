Rules / TAU-N004

No exact float comparison

enforced by Clippy kernel deny core deny edge deny
Applies to tests: no Exceptions: #[expect] + reason

Why

Exact equality of computed floats is almost always a bug.

Fix

Compare with an explicit tolerance, or use integers in fixed units.

What it checks

Lints: clippy::float_cmp, clippy::float_cmp_const
