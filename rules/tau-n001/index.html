Rules / TAU-N001

Checked arithmetic

decided by Clippy kernel deny core deny edge warn
Applies to tests: no Exceptions: #[expect] + reason

Why

Integer overflow and division by zero either panic or wrap silently depending on build profile; both are logic errors agents rarely test.

Fix

Use checked_* and return an error on None, or saturating_*/wrapping_* when that behaviour is the specification. Say which in a comment. In a kernel crate this is a proof obligation: a recorded proof that the function never fails discharges it (cargo tauten obligations).

What it checks

Lints: clippy::arithmetic_side_effects, clippy::integer_division
