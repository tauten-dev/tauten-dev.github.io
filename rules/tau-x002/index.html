Rules / TAU-X002

No crate-wide exceptions to profile lints

enforced by Tauten kernel deny core deny edge deny
Applies to tests: yes Exceptions: never

Why

A crate-level #![expect(...)] or #![allow(...)] of a profile lint switches the rule off for the whole crate.

Fix

Move the exception to the single item that needs it, with a reason.
