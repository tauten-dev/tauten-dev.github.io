Rules / TAU-P005

No process exit or leaked values outside the edge

decided by Clippy kernel deny core deny edge –
Applies to tests: no Exceptions: #[expect] + reason

Why

Exiting skips cleanup and hides control flow from callers; mem::forget silently leaks resources.

Fix

Return an error to the edge and let main decide the exit code; drop values normally.

What it checks

Lints: clippy::exit, clippy::mem_forget

Banned in kernel, core (process termination), 2 methods: std::process::exit, std::process::abort
