Rules / TAU-S001

No stubs or debug leftovers

enforced by Clippy kernel deny core deny edge deny
Applies to tests: yes Exceptions: never

Why

Agents leave todo!() and unimplemented!() behind and report the task done.

Fix

Implement the branch, or return a typed Unsupported error if the case is deliberately out of scope.

What it checks

Lints: clippy::todo, clippy::unimplemented, clippy::dbg_macro
