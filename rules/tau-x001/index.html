Rules / TAU-X001

Lint exceptions must be #[expect] with a reason

decided by Clippy kernel deny core deny edge deny
Applies to tests: yes Exceptions: #[expect] + reason

Why

#[allow] silently outlives the code it excused. #[expect(lint, reason = "...")] documents why and fails once the exception is no longer needed.

Fix

Replace #[allow(x)] with #[expect(x, reason = "why this is safe here")] on the smallest item possible, or fix the code. A module compiled into several targets (helpers under tests/ declared with mod support; by several test files) cannot carry an inner #![expect]: it is unfulfilled in every target where the lint does not fire. For dead_code only, it may carry #![allow(dead_code, reason = "...")]. Otherwise put #[expect(x, reason = "...")] on the mod declaration in exactly the targets where it fires, or remove the sharing: one integration-test target per crate (tests/it/main.rs with the tests as modules), or a support crate used as a dev-dependency.

What it checks

Lints: clippy::allow_attributes, clippy::allow_attributes_without_reason, unfulfilled_lint_expectations
