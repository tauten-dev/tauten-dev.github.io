Rules / TAU-X003

Manifest lint table loosens the profile

enforced by Tauten kernel warn core warn edge warn
Applies to tests: yes Exceptions: never

Why

[lints] entries that allow or warn profile lints have no effect under cargo tauten check but mislead readers and plain cargo clippy runs.

Fix

Remove the entry from [lints] / [workspace.lints].

In the terminal
