Rules / TAU-N003

No floating point in the kernel

enforced by Clippy kernel deny core – edge –
Applies to tests: no Exceptions: #[expect] + reason

Why

Floating point is not associative and has NaN; kernel decisions must be exact and proof-friendly.

Fix

Use integers in fixed units (cents, milliseconds, basis points) or a rational type.

What it checks

Lints: clippy::float_arithmetic
