Rules / TAU-A001

No ambient authority

decided by Clippy kernel deny core deny edge –
Applies to tests: no Exceptions: #[expect] + reason

Why

Filesystem, network, environment, clock, randomness and process access must arrive as parameters (capabilities), so a signature shows everything a function can touch and tests can substitute them.

Fix

Take a capability parameter (for example a &cap_std::fs::Dir from Authority::dir, &dyn tauten::cap::Clock, or &tauten::cap::Env) and let an edge crate construct it.
