Rules / TAU-E003

Explicit discards of results need a reason

enforced by Clippy kernel deny core deny edge deny
Applies to tests: no Exceptions: #[expect] + reason

Why

let _ = fallible() is visible but still loses the failure. In library code that is rarely right; in tests it is the normal idiom for best-effort cleanup, so tests are exempt.

Fix

Handle or propagate the result. If discarding is correct, say why: #[expect(clippy::let_underscore_must_use, reason = "best-effort cleanup")].

What it checks

Lints: clippy::let_underscore_must_use
