Rules / TAU-T002

Tier dependency direction

enforced by Tauten kernel deny core deny edge deny
Applies to tests: yes Exceptions: never

Why

Dependencies must point inward (edge -> core -> kernel); otherwise a pure crate can reach IO through its dependency.

Fix

Invert the dependency: move the shared code down a tier, or pass the capability in.
