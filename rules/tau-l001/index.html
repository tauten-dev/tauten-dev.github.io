Rules / TAU-L001

No unbounded loops outside the edge

enforced by Clippy kernel deny core deny edge –
Applies to tests: no Exceptions: #[expect] + reason

Why

A loop with no exit cannot be reasoned about or terminated by the caller.

Fix

Bound the loop, return a value from it, or move the event loop to the edge.

What it checks

Lints: clippy::infinite_loop
