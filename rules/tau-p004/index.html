Rules / TAU-P004

No panics inside fallible functions

decided by Clippy kernel deny core deny edge deny
Applies to tests: no Exceptions: #[expect] + reason

Why

A function that returns Result has promised to report failure as a value; panicking inside it breaks that promise.

Fix

Map the failure into the function's error type and return it with ?.

What it checks

Lints: clippy::unwrap_in_result, clippy::panic_in_result_fn
