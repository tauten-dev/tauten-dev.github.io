Rules / TAU-F001

Declared effects match the signature

decided by Tauten kernel warn core warn edge warn
Applies to tests: yes Exceptions: never

Why

A function's capability parameters, Result return and async bound what it can do; #[effects(..)] states that row so readers and agents see it without reading the body. The decision is proved (tauten_check_kernel::effects::verdict); classifying parameter types is by name, so a type tauten cannot classify only ever warns.

Fix

Make #[effects(..)] list exactly the labels the signature grants (the message names the missing and extra ones), or change the signature. In a crate with effects = "required" under [package.metadata.tauten], every pub fn needs #[effects(..)]; mismatches there are errors.
