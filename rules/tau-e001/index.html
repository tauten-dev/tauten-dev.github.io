Rules / TAU-E001

Never ignore a result

enforced by Rustc kernel deny core deny edge deny
Applies to tests: yes Exceptions: #[expect] + reason

Why

Dropping a Result or discarding the original error is how failures go silent.

Fix

Propagate with ?, handle the error, or wrap it with context (.map_err(|e| MyError::Io(e))) instead of discarding it.

What it checks

Lints: unused_must_use, clippy::map_err_ignore
