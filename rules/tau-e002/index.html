Rules / TAU-E002

Typed errors outside the edge

decided by Clippy kernel deny core deny edge –
Applies to tests: no Exceptions: #[expect] + reason

Why

Result<T, ()>, anyhow::Error and similar erase which failures are possible, so callers cannot handle them exhaustively.

Fix

Define an error enum (for example with thiserror) whose variants name each failure. Convert to anyhow/eyre only in edge crates.

What it checks

Lints: clippy::result_unit_err

Banned in kernel, core (type-erased error), 3 types: anyhow::Error, eyre::Report, color_eyre::Report
