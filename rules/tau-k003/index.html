Rules / TAU-K003

Kernel crate attributes

decided by Tauten kernel deny core – edge –
Applies to tests: yes Exceptions: never

Why

A kernel crate root must declare #![no_std] so the compiler enforces the absence of IO.

Fix

Add #![no_std] (or #![cfg_attr(not(test), no_std)]) at the top of the kernel crate's lib.rs, with no other condition.
