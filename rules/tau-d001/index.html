Rules / TAU-D001

Documented public API

decided by Rustc kernel warn core warn edge –
Applies to tests: no Exceptions: #[expect] + reason

Why

Undocumented public items and error cases are where callers, human or agent, guess wrong.

Fix

Add a doc comment; document each error variant a function can return under # Errors.

What it checks

Lints: missing_docs, clippy::missing_errors_doc, clippy::missing_panics_doc

In the terminal

$cargo tauten explain TAU-D001
