Rules / TAU-U002

Documented, minimal unsafe blocks

decided by Clippy kernel – core – edge deny
Applies to tests: yes Exceptions: #[expect] + reason

Why

Each unsafe operation needs its own stated justification for review.

Fix

Split blocks to one unsafe operation each and add a // SAFETY: comment explaining why the contract holds.

What it checks

Lints: clippy::undocumented_unsafe_blocks, clippy::multiple_unsafe_ops_per_block
