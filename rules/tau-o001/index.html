Rules / TAU-O001

No direct console output outside the edge

decided by Clippy kernel deny core deny edge –
Applies to tests: no Exceptions: #[expect] + reason

Why

Console output is an effect; library code that prints cannot be tested or redirected.

Fix

Return the data, or write to an impl std::io::Write passed in by the caller.

What it checks

Lints: clippy::print_stdout, clippy::print_stderr
