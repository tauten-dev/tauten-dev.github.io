Rules / TAU-A002

Authority minted outside the edge

decided by Clippy kernel deny core deny edge –
Applies to tests: yes Exceptions: #[expect] + reason

Why

Capabilities may only be created at startup in edge crates; minting them deeper defeats the point of passing them.

Fix

Accept the capability as a parameter and create it in the edge crate's main.

What it checks

Banned in kernel, core (mints authority; only an edge crate may), 1 method: tauten::cap::Authority::acquire
