Rules / TAU-G001

No hidden global state

enforced by Clippy kernel deny core deny edge –
Applies to tests: no Exceptions: #[expect] + reason

Why

Global and thread-local state creates invisible coupling between calls and breaks test isolation.

Fix

Pass the state explicitly, or own it in a struct created by the edge.

What it checks

Banned in kernel, core (global or lazily initialised shared state), 5 types: std::sync::OnceLock, std::sync::LazyLock, once_cell::sync::Lazy, once_cell::sync::OnceCell, once_cell::unsync::Lazy

Banned in kernel, core (global or thread-local state), 2 macros: std::thread_local, lazy_static::lazy_static
