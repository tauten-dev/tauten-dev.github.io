In kernel crates no profile rule admits exceptions (TAU-X004). "Tests: no" means the rule is not applied to test targets. A rule is *complete* when it misses no violation among the inputs it sees; each rule below states exactly what it decides, what it reads and what it does not see. An incomplete rule is a heuristic and never blocks, and an input a rule could not read is never reported clean (both proved: tauten_check_kernel::rule). Only complete rules are called enforced.
