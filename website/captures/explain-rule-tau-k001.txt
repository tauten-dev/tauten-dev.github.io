TAU-K001: Kernel determinism and purity

Why: Kernel decisions must be deterministic and free of shared mutable state so they can be extracted and proved (Aeneas) and replayed exactly.

Fix: Use `BTreeMap`/`BTreeSet` and plain owned values; pass state explicitly.

Decided by: Clippy
Decides: No banned non-deterministic or impure API in kernel crates.
Sees: resolved; complete: yes
Does not see: Code expanded from macros defined in other crates (clippy skips it); code disabled by `cfg`; build scripts. APIs not on the tier's ban list (clippy.toml), including dependency functions that wrap a banned one; foreign code.
Applies to tests: no
Exceptions allowed: with #[expect(.., reason)]
  kernel deny
  core -
  edge -
