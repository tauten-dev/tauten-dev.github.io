TAU-E001: Never ignore a result

Why: Dropping a Result or discarding the original error is how failures go silent.

Fix: Propagate with `?`, handle the error, or wrap it with context (`.map_err(|e| MyError::Io(e))`) instead of discarding it.

Decided by: Rustc
Decides: No `#[must_use]` value (a `Result`) dropped silently.
Sees: resolved; complete: yes
Does not see: Code expanded from macros defined in other crates (clippy skips it); code disabled by `cfg`; build scripts.
Applies to tests: yes
Exceptions allowed: with #[expect(.., reason)]
  kernel deny
  core deny
  edge deny
Lints: unused_must_use, clippy::map_err_ignore
