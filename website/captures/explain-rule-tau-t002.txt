TAU-T002: Tier dependency direction

Why: Dependencies must point inward (edge -> core -> kernel); otherwise a pure crate can reach IO through its dependency.

Fix: Invert the dependency: move the shared code down a tier, or pass the capability in.

Enforced by: Tauten
Applies to tests: yes
Exceptions allowed: with #[expect(.., reason)]
  kernel deny
  core deny
  edge deny
