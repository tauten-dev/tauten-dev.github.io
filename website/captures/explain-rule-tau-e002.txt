TAU-E002: Typed errors outside the edge

Why: `Result<T, ()>`, `anyhow::Error` and similar erase which failures are possible, so callers cannot handle them exhaustively.

Fix: Define an error enum (for example with `thiserror`) whose variants name each failure. Convert to anyhow/eyre only in edge crates.

Decided by: Clippy
Decides: No `Result<_, ()>` error type outside the edge.
Sees: resolved; complete: yes
Does not see: Code expanded from macros defined in other crates (clippy skips it); code disabled by `cfg`; build scripts.
Applies to tests: no
Exceptions allowed: with #[expect(.., reason)]
  kernel deny
  core deny
  edge -
Lints: clippy::result_unit_err
Banned (type-erased error): anyhow::Error, eyre::Report, color_eyre::Report
