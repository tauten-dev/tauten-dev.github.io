TAU-P002: No explicit panics

Why: A panic is an untyped, unrecoverable failure that callers cannot see in the signature.

Fix: Return a typed error variant. If the state is truly impossible, restructure the types so it cannot be represented.

Enforced by: Clippy
Applies to tests: no
Exceptions allowed: with #[expect(.., reason)]
  kernel deny
  core deny
  edge warn
Lints: clippy::panic, clippy::unreachable
