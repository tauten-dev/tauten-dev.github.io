TAU-P004: No panics inside fallible functions

Why: A function that returns Result has promised to report failure as a value; panicking inside it breaks that promise.

Fix: Map the failure into the function's error type and return it with `?`.

Enforced by: Clippy
Applies to tests: no
Exceptions allowed: with #[expect(.., reason)]
  kernel deny
  core deny
  edge deny
Lints: clippy::unwrap_in_result, clippy::panic_in_result_fn
