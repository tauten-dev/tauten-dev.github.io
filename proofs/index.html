Proofs

Proved means a Lean theorem about the Charon/Aeneas translation of the crate that ships, checked by the five steps below.

tauten's own decisions (tiers, severity, exceptions, the baseline ratchet, the effects verdict) live in the no_std crate tauten-check-kernel and are proved this way. cargo tauten init --proofs sets up the same gate for your kernel crates.

The gate

  1. Extract. Charon and Aeneas translate the kernel crate to Lean.
  2. Drift. The translation must match the committed proofs/Extracted/.
  3. Build. lake build checks every proof.
  4. Audit. Audit.lean: axioms only propext, Classical.choice, Quot.sound; every extracted function is covered by a claim.
  5. Mutants. Each deliberately broken copy of the Rust must fail its named theorems.
