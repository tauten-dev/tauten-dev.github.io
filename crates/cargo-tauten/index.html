cargo-tauten

edge●Exercisedcrates.iodocs.rs

Run the tauten strictness profile over a Cargo workspace.

What it does

The CLI runs one cargo check with itself as the workspace rustc wrapper, so each crate gets exactly the lints and clippy configuration of its own tier, and then adds tauten's structural checks. It prints one diagnostic per finding, as text or as one JSON object per line, each with a rule ID, a repair hint and what enforces the rule. It exits with 1 when an error-level finding remains, 0 otherwise, and 2 when the tool itself fails.

What it does not do

  • No automatic fixes. It reports; the code is changed by you or your agent.
  • No LSP or SARIF output.
  • It does not replace clippy. It runs clippy, with the profile's lints and a generated configuration.
