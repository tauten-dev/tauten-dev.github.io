tauten-macros

core●Exercisedcrates.iodocs.rs

Procedural macros for tauten: refinement types and runtime-checked contracts.

What it does

#[newtype] and #[refined] define wrappers whose field cannot be reached or built except through new or try_new. #[requires] and #[ensures], with old(..), check contracts on every call in every build profile. A violation is a returned error, never a panic, and there is no release-mode switch that turns the checks off.

What does not compile

What it does not do

  • Predicates are checked at run time. Nothing is propagated or proved statically.
  • Contracts apply only to functions that return Result<T, E> with E: From<tauten::ContractViolation>.
  • No async fn yet ("contracts on async functions are not supported yet").
  • No generic newtypes yet ("generic newtypes are not supported yet").
  • old(..) snapshots only Copy values; it never clones a resource.
  • No Kani lowering yet.
