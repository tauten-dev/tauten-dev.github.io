tauten

edge●Exercisedcrates.iodocs.rs

Capability tokens, refinement types and checked contracts for the tauten Rust strictness profile.

What it does

Authority is created once, in an edge crate, with Authority::acquire, and handed down as narrow capabilities: a clock, an environment snapshot and, with the fs feature, a directory handle. Core code takes those as parameters, so a signature shows what it can touch. The crate also re-exports the macros from tauten-macros.

What it does not do

  • it does not sandbox anything. Code that calls std::fs directly still can; the profile's lints are what stop that in kernel and core crates, and dependencies are not covered.
