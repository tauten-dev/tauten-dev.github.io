Crates / tier core

tauten-check

core●Exercisedcrates.iodocs.rs

Pure analysis for the tauten Rust strictness profile: rules, lint flags and structural checks.

What it does

The analysis crate holds the rule table (rules.toml), the agent profile, lint flags and clippy.toml generation per tier, the mapping from compiler messages to rule IDs, and the structural checks. It performs no IO; the CLI builds the workspace model from disk and hands it in.

Two design decisions

  • Lints compile at warn level; the profile assigns severity. With deny levels, rustc fails and dependents are never checked.
  • No rustc forbid. Derive macros (clap, among others) emit #[allow(clippy::...)], which rustc rejects under forbid. "No exceptions" is a structural check instead (TAU-X004).

From docs/STATUS.md, Design decisions.

What it does not do

  • No IO. It is a core crate and is checked with its own profile.
  • Structural checks parse source with syn. They are syntactic, not type-aware.
