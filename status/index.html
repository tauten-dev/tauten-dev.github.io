Benchmark

We measured defect reduction and did not find it: 2 escaped defects in 200 unassisted trials; 0 of 120 sampled findings were reachable defects. tauten makes no defect-reduction claim.

Agents without the profile almost never shipped a defect the hidden tests catch, so the held-out run was stopped by its preregistered rule. The profile does change the code; on these tasks that code was not wrong. The harness, design and pilot are in bench/README.md; the audit is summarised under Known gaps in docs/STATUS.md.

Design decisions made while building (with reasons)

  • The CLI is the rustc wrapper. One cargo check with RUSTC_WORKSPACE_WRAPPER=cargo-tauten, so each crate gets exactly its own tier's flags. cargo clippy -- flags applied flags to dependencies too.
  • Lints compile at warn level; the profile assigns severity. With deny levels, rustc fails and dependents are never checked.
  • No rustc forbid. Derive macros (clap, among others) emit #[allow(clippy::...)], which rustc rejects under forbid. "No exceptions" is a structural check instead (TAU-X004).
  • Separate profile for test targets (in_tests). Calibrated on writfold, where most panic and IO findings were legitimate test code.
  • Refined types live in a private generated module, so even the defining module cannot bypass try_new.
  • Contracts only on Result-returning functions. A violation is a returned error in every build profile; there is no release-mode disabling and no panic.
  • Baseline keyed without line numbers, and it may only shrink.
  • The build directory is keyed by a hash of the profile and tier map, because cargo does not fingerprint what a wrapper adds.

Known gaps

  • The capability rule is discipline, not confinement (see MAPPING.md).
  • The kernel's arithmetic and indexing rules duplicate what an Aeneas proof already establishes (dry-run report). P5 subsumes them only for functions with a recorded, current, total proof. Writfold's adoption branch subsumes 142 of its 159 extracted-kernel findings this way, after rewriting four helpers to be total (get instead of indexing; 10 more findings disappeared with the indexing). The remaining 7 are in splice, whose only panic is a length overflow past usize::MAX.
  • No credit through callers: a helper with a precondition gets no subsumption even when every caller is proved total.
  • tauten trusts the project's gate output, including its total-shape check; it does not re-check the Lean theorems itself.
  • Any edit under a claimed crate or proofs/ stales every claim of that crate (writfold: a 1.5 h re-run). The workspace manifest (without its version lines) and the toolchain pin count too, since 2026-11-19.
  • Mutant counting differs: writfold's gate counts only direct proof failures, tauten's also counts theorems that depend on a broken one.
  • S002 (placeholder comments) is a heuristic.
  • The benchmark hits a ceiling. Three calibration rounds without the profile (200 trials, Sonnet 5.5 and Haiku 5.5, 7 tasks on 3 hosts, hidden oracles in dev and release builds) had 2 escaped defects. The preregistered go/no-go rule (10-26 of 40 on the probe tasks) came out no-go (Sonnet 1/40, Haiku 0/40), so the held-out run was not started.
  • Finding validity (audit E1, registered before classifying): of 120 sampled deny-level findings in that agent-written code, two independent classifiers confirmed 0 as reachable defects (exact 95% interval 0-3.0%); 118 refuted with a written bound argument, 2 undetermined. Neither escaped defect was on a flagged line. On these hosts the profile's findings are predominantly not defects. Untested: whether those bounds survive later edits (maintenance chains, not run).
  • #[refined] wraps only tauten::refine::Frozen types (primitives, String, std containers of those): interior mutability or a user-written Clone could break a checked predicate (external review, 2026-11-19). Predicates are arbitrary closures, not a checked fragment.
  • Contracts do not yet support async fn or generic newtypes; they have no Kani (cfg(kani)) lowering yet.
  • No defect-reduction benefit established. The pilot could not separate the arms, the held-out run was stopped by its own go/no-go rule, and audited findings were not defects; nothing here supports a claim that the profile reduces escaped defects.
